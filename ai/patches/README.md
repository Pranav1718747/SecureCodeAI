# AI Module: Patches

## Purpose
Autofix engine generating, validating, and applying git diff security patches.

## Key Components
- `patch_generator.py`: AI-powered security patch generator crafting context-aware code remediations.
- `patch_applier.py`: Applies unified git diff patches securely against repository source code.
- `git_diff.py`: Parses, validates, and generates standardized git unified diff format representations.
